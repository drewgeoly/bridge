# Vercel URLs: Deployment vs Domain

## Quick Answer

- **Deployment URL**: Vercel's auto-generated URL (e.g., `bridge-app.vercel.app`)
- **Custom Domain**: Your own domain name (e.g., `bridge.app`)

Use whichever URL you want users to access your app with for the redirect URI.

## Deployment URL (Default)

When you deploy to Vercel, you automatically get a deployment URL:

**Format:**
- `your-project-name.vercel.app`
- Or sometimes: `your-project-name-{random-hash}.vercel.app`

**Example:**
- `bridge-l6ikeok18-drew-geolys-projects.vercel.app`
- `my-bridge-app.vercel.app`

**Where to find it:**
1. Go to your Vercel project dashboard
2. Look at the top of the page
3. You'll see it listed under "Domains" or in the deployment details

**Use this if:**
- You don't have a custom domain
- You're okay with the `.vercel.app` URL
- You want to test quickly without domain setup

## Custom Domain

A domain you own and connect to Vercel:

**Examples:**
- `bridge.app`
- `myapp.com`
- `bridge.yourdomain.com`

**Where to set it up:**
1. Go to your Vercel project → **Settings** → **Domains**
2. Click **Add Domain**
3. Enter your domain name
4. Follow DNS configuration instructions

**Use this if:**
- You have a domain name
- You want a branded URL
- You want a shorter, memorable URL

## Which One to Use for OAuth Redirect URI?

**Use the URL that users will actually visit your app with.**

### Option 1: Using Deployment URL
```
GOOGLE_CALENDAR_REDIRECT_URI=https://your-project-name.vercel.app/api/calendar/callback
```

### Option 2: Using Custom Domain
```
GOOGLE_CALENDAR_REDIRECT_URI=https://bridge.app/api/calendar/callback
```

### Option 3: Using Both (Recommended)
Add **both** redirect URIs in Google Cloud Console:
- `https://your-project-name.vercel.app/api/calendar/callback`
- `https://bridge.app/api/calendar/callback` (if you have a custom domain)

This way, OAuth works regardless of which URL users access.

## Important Notes

1. **Must match exactly**: The redirect URI in your environment variable must **exactly match** one of the URIs you added in Google Cloud Console
2. **HTTPS required**: Production URLs must use `https://` (not `http://`)
3. **No trailing slash**: Don't add a trailing slash (e.g., use `/api/calendar/callback` not `/api/calendar/callback/`)
4. **Case sensitive**: URLs are case-sensitive, so match exactly

## Finding Your Current Deployment URL

**Method 1: Vercel Dashboard**
1. Go to [vercel.com](https://vercel.com)
2. Open your project
3. Look at the top - you'll see your deployment URL

**Method 2: From a Deployment**
1. Go to **Deployments** tab
2. Click on any deployment
3. The URL is shown at the top

**Method 3: From Domain Settings**
1. Go to **Settings** → **Domains**
2. You'll see all configured domains listed

## Example Setup

If your Vercel project is named `bridge-app` and you deployed it:

**Deployment URL:**
```
https://bridge-app.vercel.app
```

**Redirect URI for Google OAuth:**
```
https://bridge-app.vercel.app/api/calendar/callback
```

**Environment Variable:**
```
GOOGLE_CALENDAR_REDIRECT_URI=https://bridge-app.vercel.app/api/calendar/callback
```

## Summary

- **Deployment URL**: Auto-generated by Vercel (`.vercel.app`)
- **Custom Domain**: Your own domain name
- **For OAuth**: Use whichever URL users access your app with
- **Best Practice**: Add both to Google Cloud Console if you have both
